## Why

This project is a fresh OpenSpec learning workspace with no application yet. A minimal hello world page establishes a runnable baseline, validates the propose → apply workflow end-to-end, and gives something concrete to open in a browser.

## What Changes

- Add a single static web page that displays "Hello, World!" (or equivalent greeting)
- Add a simple way to open or serve the page locally (e.g., open `index.html` directly or a one-line static server)
- No backend, database, or authentication
